二次剩余

勒让德符号

(np)={1,n在模 p 意义下的二次剩余−1,n在模 p 意义下的非二次剩余0,n≡0( mod p) \large{ \left( \frac{n}{p} \right) = \begin{cases} 1, &n \text{在模 $ p $ 意义下的二次剩余}\\\\ -1, &n \text{在模 $ p $ 意义下的非二次剩余}\\\\ 0, &n \equiv 0 (\bmod p) \end{cases} } (pn​)=⎩⎨⎧​1,−1,0,​n在模 p 意义下的二次剩余n在模 p 意义下的非二次剩余n≡0(modp)​

即：

(np)≡np−12( mod p) \large{ \left( \frac{n}{p} \right) \equiv n^{\frac{p - 1}{2}} (\bmod p) } (pn​)≡n2p−1​(modp)

定理

n2≡(p−n)2p 的二次剩余和二次非剩余的个数均为 p−12 （除 0） \large{ n^2 \equiv (p - n)^2 } \\\\ \large{ \text{$ p $ 的二次剩余和二次非剩余的个数均为 $ \frac{p - 1}{2} $ （除 $ 0 $）} } n2≡(p−n)2p 的二次剩余和二次非剩余的个数均为 2p−1​ （除 0）

  2. 合法解 x≡(a+ω)p+12( mod p) x \equiv (a + \omega)^{\frac{p + 1}{2}} (\bmod p) x≡(a+ω)2p+1​(modp) 。
