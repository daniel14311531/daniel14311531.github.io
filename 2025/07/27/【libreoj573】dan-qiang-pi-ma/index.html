【libreoj573】单枪匹马

做法

可以证明直接计算不需要约分，可以直接取模。
证明：若 xy \frac{x}{y} yx​ 中 x,y x, y x,y 互质，则 a+xy=ay+xy a + \frac{x}{y} = \frac{ay + x}{y} a+yx​=yay+x​ 中 ay+x,y ay + x, y ay+x,y 互质（考虑辗转相除法中 gcd(X, Y) = gcd(Y, X % Y) (Y = y, X = ax + y) ）。
这样可以得到 35pts 35 pts 35pts 。
设 f[a0…an]=x[a0…an]y[a0…an] f[a_0 \dots a_n] = \frac{x[a_0 \dots a_n]}{y[a_0 \dots a_n]} f[a0​…an​]=y[a0​…an​]x[a0​…an​]​ ，则：

x[a0…an]y[a0…an]=a0+y[a1…an]x[a1…an]=y[a1…an]+a0x[a1…an]x[a1…an] \frac{x[a_0 \dots a_n]}{y[a_0 \dots a_n]} = a_0 + \frac{y[a_1 \dots a_n]}{x[a_1 \dots a_n]} = \frac{y[a_1 \dots a_n] + a_0 x[a_1 \dots a_n]}{x[a_1 \dots a_n]} y[a0​…an​]x[a0​…an​]​=a0​+x[a1​…an​]y[a1​…an​]​=x[a1​…an​]y[a1​…an​]+a0​x[a1​…an​]​

由于这些都是最简分数，所以：

x[a0…an]=y[a1…an]+a0x[a1…an]y[a0…an]=x[a1…an] x[a_0 \dots a_n] = y[a_1 \dots a_n] + a_0x[a_1 \dots a_n]\\\\ y[a_0 \dots a_n] = x[a_1 \dots a_n] x[a0​…an​]=y[a1​…an​]+a0​x[a1​…an​]y[a0​…an​]=x[a1​…an​]

可以得到：

x[a0…an]=x[a2…an]+a0x[a1…an]y[a0…an]=y[a2…an]+a0y[a1…an] x[a_0 \dots a_n] = x[a_2 \dots a_n] + a_0x[a_1 \dots a_n]\\\\ y[a_0 \dots a_n] = y[a_2 \dots a_n] + a_0y[a_1 \dots a_n] x[a0​…an​]=x[a2​…an​]+a0​x[a1​…an​]y[a0​…an​]=y[a2​…an​]+a0​y[a1​…an​]

考虑在图上的意义。在一个由 n n n 个节点的有向图，i i i 向 i+1 i + 1 i+1 连边权为 ai a_i ai​ 的边，向 i+2 i + 2 i+2 连边权为 1 1 1 的边。最后的值为 1 1 1 到 n n n 的路径边权乘积之和。显然这些边可以反向。可以得到：

x[a0…an]=anx[a0…an−1]+x[a0…an−2]y[a0…an]=any[a0…an−1]+y[a0…an−2] x[a_0 \dots a_n] = a_nx[a_0 \dots a_{n-1}] + x[a_0 \dots a_{n - 2}]\\\\ y[a_0 \dots a_n] = a_ny[a_0 \dots a_{n-1}] + y[a_0 \dots a_{n - 2}] x[a0​…an​]=an​x[a0​…an−1​]+x[a0​…an−2​]y[a0​…an​]=an​y[a0​…an−1​]+y[a0​…an−2​]

然后这个东西可以矩阵转移。

Ai=[ai110],invi=[011mod−ai][ansxansy]=∏i=lrAi=(∏i=1rAi)×(∏i=1l−1invi) A_i = \left[ \begin{matrix} a_i&1\\\\ 1&0 \end{matrix} \right], inv_i = \left[ \begin{matrix} 0&1\\\\ 1&mod - a_i \end{matrix} \right]\\\\ \left[ \begin{matrix} ansx\\\\ ansy \end{matrix} \right] = \prod_{i = l}^{r} A_i = (\prod_{i = 1}^{r}A_i) \times (\prod_{i = 1}^{l - 1}inv_i) Ai​=​ai​1​10​​,invi​=​01​1mod−ai​​​​ansxansy​​=i=l∏r​Ai​=(i=1∏r​Ai​)×(i=1∏l−1​invi​)

维护前缀积即可。
时间复杂度 O(n+m) O(n + m) O(n+m) （矩阵乘法常数堪比一个 log⁡ \log log ） 。
