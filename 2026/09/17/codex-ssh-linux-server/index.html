本地 codex 连接 linux 服务器

发表于 2026-09-17 本文字数： 1.9k 阅读时长 ≈ 2 分钟
无

参考链接：在没有梯子的服务器上使用 VSCode Codex 的完整指南

前置条件

  • 本地安装 codex ，有可以使用的 chatgpt 账号（=本地有代理，代理不要开虚拟网卡）
  • 本地代理端口 127.0.0.1:7897 （clash verge 默认设置？）
  • vscode 可以通过 Remote-SSH 连接到 linux 服务器，且 vscode 装有 codex 插件
  • 服务器安装 codex （通过 npm，可以没有 root 权限）

Step 1 配置 SSH 隧道

编辑本地的 ~/.ssh/config 文件，添加以下内容：

  • RemoteForward（远程转发）：在 linux 服务器上开通 SSH 隧道，通向本地内网里的某个服务。
  • LocalForward（本地转发）：在你本地开通 SSH 隧道，通向远程服务器里的某个服务。
  • ServerAliveInterval、ServerAliveCountMax：用于保持 SSH 连接的活跃状态。

Step 2 复制 Codex 登录凭证到服务器

  • 在本地登录 codex 后，找到 ~/.codex/auth.json 文件，并将其复制到服务器上的相同位置。
  • 上传后不要在本地退出或重新登录 Codex，否则本地的 token 会更新，服务器上的也会跟着过期，就要重新粘过去。
  • 每隔一段时间如果服务器端 Codex 提示认证失败，重新从本地复制一次最新的 auth.json 即可。
